# CONVENTIONS

## NAMING
### Rooms
- Rooms will be named in snake_case with descriptive and long names

### Loading zones
- Load zones will be named in UpperCamelCase with Door as the first word, then Wall {NWSE}, then Direction2 {Upper,Middle,Lower} (i.e. DoorWestUpper, DoorSouthMiddle)
- Subsequent loading zones beyond this will simple have an underscore followed by a number
